# Sentiment Analysis using NLP

## Overview
Built an end-to-end NLP pipeline for sentiment-based rating prediction on Amazon reviews.

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- VADER + RoBERTa sentiment extraction
- Random Forest and XGBoost models
- PCA dimensionality reduction

## Dataset
- 568K+ Amazon reviews

## Results
- Achieved 79.5% classification accuracy

## Tech Stack
- Python
- Scikit-learn
- XGBoost
- Pandas
- NLP
